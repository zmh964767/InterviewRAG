# 日志规范

> InterviewRAG 后端日志标准

---

## 日志库

用 Python 标准库 `logging`，配置统一在 `app/main.py`。

---

## 日志级别

| 级别 | 用途 | 示例 |
|------|------|------|
| `DEBUG` | 开发调试信息 | 向量检索结果、API 请求详情 |
| `INFO` | 正常业务事件 | 用户查询成功、知识库导入完成 |
| `WARNING` | 需要注意但不影响运行 | 查询结果为空、重试外部调用 |
| `ERROR` | 错误但服务仍运行 | 智谱 API 调用失败、ChromaDB 写入失败 |
| `CRITICAL` | 服务不可用 | 数据库连接断开、配置缺失 |

---

## 必须记录的事件

- 每次 API 请求：方法、路径、状态码、耗时
- 每次 LLM 调用：模型名、token 用量、耗时
- 每次知识库导入：文档数量、耗时
- 所有 ERROR 和 CRITICAL 级别错误

---

## 禁止记录

- ❌ API Key 或密钥
- ❌ 用户原始问题中的敏感信息（MVP 阶段暂不考虑）
- ❌ 完整的向量数据（太大）

---

## 日志格式

```
%(asctime)s | %(levelname)-8s | %(name)s | %(message)s
```

示例输出：
```
2026-06-06 18:30:00 | INFO     | app.api.query | 查询成功: question_id=42, 耗时=1.2s
```
