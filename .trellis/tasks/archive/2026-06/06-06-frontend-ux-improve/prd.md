# PRD: 前端体验优化

## 目标

在已完成的 Editorial Technical 视觉设计基础上，修复功能缺陷并补充核心交互体验。

## 已完成

- ✅ Editorial Technical 视觉风格（Crimson Pro + 暖奶油色调 + 纸质纹理）
- ✅ 侧边栏布局 + 知识库统计
- ✅ 欢迎页 + 功能卡片 + 快速提问
- ✅ 消息气泡 + 来源引用卡片

## 待实现功能

### P0 - 必须修复
1. **快捷问题按钮不工作**：欢迎页和输入框的建议问题点击后应直接发送消息
2. **Markdown 渲染**：AI 回答中的代码块、标题、列表等需要正确渲染（引入 react-markdown）

### P1 - 核心体验
3. **流式打字指示器**：AI 生成时显示光标闪烁动画
4. **多对话管理**：侧边栏 Tab 切换（对话 | 知识库），对话 tab 显示历史列表，支持新建/切换/删除，localStorage 持久化
5. **消息操作**：复制消息内容、重新生成回答

### 不做的
- 深色模式（当前暖色调已足够有特色）
- 用户认证
- 管理后台

---

## 验收标准

- [ ] 快捷问题按钮点击后直接发送消息
- [ ] AI 回答正确渲染 Markdown（代码高亮、标题、列表）
- [ ] 流式输出时有打字光标动画
- [ ] 侧边栏显示对话列表，可新建/切换/删除
- [ ] 刷新页面后对话历史保留（localStorage）
- [ ] 消息可复制、可重新生成

---

## 技术约束

- 不引入组件库（保持轻量）
- 用 react-markdown + remark-gfm + rehype-highlight 处理 Markdown
- 对话持久化用 localStorage（容量 ~80+ 对话）
- 对话标题取第一条消息前 N 字，CSS 自然截断
- 侧边栏 Tab 切换：对话 | 知识库
